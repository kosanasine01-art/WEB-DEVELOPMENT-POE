README – OLWETHU UTHANDO Boutique
About My Website

Pages on My Website

My website includes the following pages:

Index Page: This is the first page visitors see when they open my website.
Home Page: This page introduces OLwethu UTHANDO and gives visitors an idea of what my brand is about.
Signup Page: This page allows visitors to enter their details and register.
Shop Page: This page will display the different clothing items available from my brand.
About Page: This page explains more about my brand and what inspired it.
Contact Page: This page allows customers to get in touch with the business.
Colours and Design

For my website, I decided to use:

Mauve
Dusty pink
Dark brown
Cream
White

I chose these colours because I wanted the website to look elegant, feminine and modern. I also want the design to be simple enough for visitors to navigate without struggling to find things.

Tools I Used

I used the following tools to create my website:

HTML: To create the different website pages.
CSS: To add colours, fonts, layouts and styles.
Notepad: To write and edit my HTML and CSS code.
CSS Grid and Flexbox: To help arrange the content on my website.
Media Queries: To help my website adjust to different screen sizes.
How to Open My Website

To view my website, open the project folder and double-click on the index.html file. The website will open in a browser, where you can use the navigation links to visit the different pages.
